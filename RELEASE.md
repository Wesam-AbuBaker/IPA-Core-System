# IPA-Core-System Release Definition

## Version
V1

## Date
2026-03-30

## Status
Stable baseline

## System
IPA Lab Management System

## Scope
Google Apps Script web app for managing schools, labs, dashboard views, and lab settings through Google Sheets.

## Current Capabilities
- User access based on `PERMISSIONS`
- Support for internal domain users and external users through shared access flow
- Filter schools and labs based on assigned permissions
- View schools, labs, settings, and dashboard from the web interface
- Update lab settings from the dashboard
